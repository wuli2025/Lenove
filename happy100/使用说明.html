幸福小事

让生活更幸福的 100 件小事 · v1.0

一句话说明白：网页版已经上线，手机电脑打开 happy.llmwiki.cloud 就能用；安卓也可以装文件夹里的 .apk。 数据默认只存在你自己设备上，想跨设备用就开「云同步」（第 4 节）。
在线地址
正式域名 https://happy.llmwiki.cloud
备用域名 https://happy-e0k.pages.dev
两个是同一个站点。iPhone 直接用 Safari 打开正式域名， 「分享 → 添加到主屏幕」就是一个完整的 App，不用电脑、不用 Mac。

1安卓手机

  1. 把 幸福小事.apk 传到手机上（微信文件传输助手 / QQ / 数据线都行）
  2. 在手机上点开它，系统会问「是否允许安装未知来源应用」，选允许
  3. 装完桌面上就有一个小太阳图标了 ☀️

如果这个装不上，试试文件夹里的 幸福小事-备用包.apk（调试版，兼容性更宽松）。

2iPhone / iPad

先说清楚一件事：iPhone 上的 .ipa 安装包必须在 Mac 电脑的 Xcode 里编译和签名， 这是苹果的硬性限制，Windows 电脑上做不出来。

但下面这个办法效果几乎一样，而且不需要 Mac、不需要开发者账号、不用花钱：

办法 A：添加到主屏幕（推荐，一分钟搞定）

  1. 用 iPhone 的 Safari 打开 https://happy.llmwiki.cloud
  2. 点屏幕底部中间的分享按钮 （方框里一个向上箭头）
  3. 往下滑，点「添加到主屏幕」 → 添加

桌面上就出现小太阳图标了，点开是全屏的，没有浏览器地址栏，和真 App 一模一样。 站点是 HTTPS 的，离线缓存也会生效——装好之后没网也能打开用。

必须用 Safari。微信里打开、或者用 Chrome，都没有「添加到主屏幕」这个选项。

办法 B：不想联网，用局域网自己开

  1. 手机和电脑连同一个 WiFi
  2. 双击文件夹里的 启动网页版.bat，黑窗口会列出几个网址
  3. iPhone 的 Safari 打开那个 192.168.x.x:5178，同样「添加到主屏幕」

完全不经过外网。代价是这条路是 HTTP，浏览器不给注册离线缓存， 而且每次都要开着电脑那个窗口。日常用还是办法 A 省事。

办法 C：真的要出 .ipa（需要一台 Mac）

  1. 把 iOS-Xcode工程 整个文件夹拷到 Mac 上
  2. 用 Xcode 打开里面的 App/App.xcworkspace
  3. 左上角选好你的 Apple ID 签名，接上 iPhone，点运行

用免费 Apple ID 签的话，App 每 7 天要重新签一次；付费开发者账号（$99/年）可以签一年。

4账号与云同步

默认情况下数据只存在你这台设备上，不联网、不上传。 想在手机和电脑之间同步、或者怕清了浏览器数据会丢，就去 我的 → 云同步 → 注册，填个邮箱和密码就行。

下次不用再登录

注册或登录时勾着「在这台设备上记住我」（默认勾着）， 登录状态就存在这台设备里。以后打开 App 直接进，不会再问你密码。 想换设备、或者数据丢了，用邮箱 + 密码登录就能全部拿回来。

数据是加密的

  1. App 随机生成一把数据密钥，你写的东西都用它加密
  2. 这把密钥被「邮箱+密码」派生出的锁包住，再存到服务器
  3. 服务器只有被锁住的密钥和加密后的密文，没有密码就永远打不开

所以 Cloudflare 看不到、我也看不到你写了什么。 邮箱不会验证、不会发广告——整个注册过程根本不经过任何邮件服务。

关于恢复码
注册时会给你一串恢复码，比如 JBBGQ-2N2A2-WSZ9V-KS4CN。 它和密码是两把各自独立的钥匙，开同一个盒子——忘了密码就用它进去，然后重设密码。

注册那一屏有个「发到我邮箱」按钮，点了会打开你自己的邮件 App 并填好内容， 不经过任何服务器，你点发送就存进自己邮箱了，以后翻邮件就能找到。

⚠️ 密码和恢复码两个都丢了，云端那份就真的打不开了。 没有「找回密码」这种功能，因为服务器根本没有能解开它的钥匙。 这是端到端加密的代价，也是它的意义。
情况会怎样
两台设备各打了几件合并，两边的都算上
同一天两边不一样按最后修改时间取新的；但感悟永远合并，不会被覆盖掉
密码输错提示「密码不对」，并告诉你可以用恢复码进去
改了密码旧密码立刻失效，恢复码依然有效
退出登录只断开这台设备，本机和云端数据都保留，登回来就有
清空所有记录会额外问一次要不要连云端一起删

同步是自动的：改动后过两秒自动上传，每次打开 App 或从后台切回来会自动拉取。 「我的 → 云同步」那里也有「立即同步」可以手动点。

密码强度直接决定安全性。数据是用你的密码加密的， 所以别用 12345678 这种。注册时下面会实时提示强度， 能给到「很不错」最好。
技术上：密钥用 PBKDF2 跑 30 万轮派生，AES-GCM-256 加密。 账号指针的定位 id 由「邮箱+密码」一起哈希得到——只知道你的邮箱， 连你的数据存在哪儿都定位不到。

5周报发到邮箱

两种方式：

  • 手动：报告页 → 本周周报 → 点「📮 发到我邮箱」
  • 自动：设置里打开「每周把周报发到我邮箱」，填好收信邮箱。 之后每周第一次打开 App 时，会自动把上一周的周报发给你，一周只发一次。

邮件正文是纯文本的完整周报：每天完成几件的柱状条、分类分布、 每天的心情和随笔、本周所有感悟，都在里面。

说清楚两件事：
① 不是服务器定时推送，是你打开 App 时触发的。真正的定时推送需要服务器能读你的数据， 而你的数据是加密的，服务器读不了——所以只能由客户端解密后自己拼好再发。 好在这是个每天都会打开的 App，实际效果差不多。

② 周报正文这一段会经过服务器，因为它要变成邮件，而邮件本来就是明文传输的。 你的完整数据依然只以密文形式存在云端。不想让任何内容经过服务器的话，就别开这个功能， 用「复制周报」自己发。
不注册账号也完全能用。数据一样好好地存在本地。 只是建议偶尔去「我的 → 导出我的全部数据」存一份 JSON 备份， 换手机时用「从文件恢复」导回来。

7想自己改内容

100 件小事全都写在 网页版/data.js 里，用记事本就能改，格式一看就懂：

{ id: 1, cat: 'morning', text: '睁眼后先别拿手机，躺着伸个大大的懒腰',
  tip: '手机可以晚三分钟再见到你', type: 'work', weather: 'indoor', mins: 1 },

cat 是分类、tip 是灰色小字、type 填 work（忙碌日）或 life（松弛日）、 weather 填 indoor 或 outdoor、mins 是大概几分钟。改完刷新页面就生效。

改完想重新打 APK：在项目源码目录下跑 npx cap sync android， 然后进 android 目录跑 gradlew assembleRelease。 注意路径里不能有中文，Gradle 会拒绝编译。
