# MicaBase 基座实现计划（按 PRD v0.2）

> **For agentic workers:** 本计划由本会话内联执行（executing-plans 语义）。步骤用 `- [ ]` 跟踪。

**Goal:** 按 `PRD-米糕基座-v0.2.html` 实现单仓 MicaBase：Rust workspace（crates/mica 单核心 crate + apps/desktop 占位壳），mica-server（axum + SSE + 控制通道）P0 形态端到端可运行、可压测、可验证。

**Architecture:** 单 crate 六模块（core/runtime/provider/engine/doctor/server），依赖方向 server→engine→provider→runtime→core 由 scripts/check-boundaries.ps1 强制。三引擎：ApiEngine（reqwest+rustls 直连 Anthropic 兼容 /v1/messages）、ClaudeEngine/CodexEngine（tokio::process + stdin prompt + stream-json/JSONL 解析 + Job Object 杀树）。调度器 = 双信号量池（api/cli）+ 三级优先级队列 + 租户在飞上限 + 背压 429。SQLite（rusqlite bundled, WAL, 单写者线程）落 tasks/events/usage。控制通道 = REST 上行（cancel/pause/resume/PATCH）+ 每任务 ctrl mpsc + SSE 回执（ControlAck/StateChanged），SSE 以 Last-Event-ID 从 events 表续传。

**Tech Stack:** tokio / axum / reqwest(rustls) / rusqlite(bundled) / dashmap / serde / tracing / uuid / windows-sys(Job Object) 。

**范围（P0 本期）:** ApiEngine + Claude/Codex CLI 引擎 + 调度器 + 供应商中心（预设/绑定注入/探测/故障转移）+ SSE 事件出口 + 4.8 控制通道 + doctor 三级解析 + SQLite 持久化 + mock-claude 冒烟 + Dockerfile。
**不做（PRD 已声明 P1/P2）:** MicaLoop/MicaAgent、Resume 会话、Tauri 桌面壳实体（留占位 README）、WS、OS 凭据库、PostgreSQL。

## 契约锁定（core 关键签名）

```rust
pub enum EngineId { Api, Codex, Claude }
pub enum Priority { High, Normal, Low }           // 队列序 High<Normal<Low
pub enum TaskState { Queued, Held, Running, Paused, Canceled, Done, Error }
pub enum ControlOp { Cancel, Pause, Resume, Patch }
pub struct TaskLimits { timeout_secs: u64, max_output_bytes: u64 } // 默认 1800 / 8MiB
pub struct TaskSpec { id, tenant, engine, prompt(≤2MB), system_prompt, cwd, model, priority, limits, provider_override }
pub enum AgentEvent { Queued{position}, Started{pid}, Delta{text}, ToolUse{name,summary},
  Usage{input_tokens,output_tokens}, ControlAck{op,ok}, StateChanged{state},
  Done{result}, Error{code,detail,retryable} }     // serde tag="type", snake_case
pub struct ProviderBinding { id, base_url, auth_field, secret, models: ModelMap } // to_env() 先清受管键
```

REST（与 PRD 3.3/4.7/4.8 一致）：`POST /v1/tasks`(202/429)、`GET /v1/tasks/:id`、`GET /v1/tasks/:id/events`(SSE)、`POST /v1/tasks/:id/cancel|pause|resume`(202/410/409)、`PATCH /v1/tasks/:id`、`GET /healthz`、`GET /metrics`、`GET|POST /v1/providers`、`POST /v1/providers/:id/activate|probe`。
